## 1. 面试官思路页（用户向 trace）—— 先做

**给用户看什么**：一场面试里面试官每一步的意图和它对你的判断，只保留能帮你下次改进的部分。

**数据**：全部已有，纯投影，不调模型。事件日志里 `interviewer_said` 带 `action / why / topic / facet`，`ledger_written` 带一行证据账，`candidate_said` 带 `signal`（答了 / 答空 / 求助 / 答不上 / 不是我做的 / 要结束）。`views.traceTurns` 已经把它们按回合拼好；新写一个 `views.reviewTrail(rows, areas)` 只挑用户向字段并翻成人话。

**页面**：报告页新增一节「面试官是怎么问你的」，放在"逐段反馈"之前、"简历上的说法"之后；体验版同一棵组件树（事件在浏览器会话文档里，`TrialMockTracePage` 已有读取路径）。

- 按材料分组（项目 / 基础 / 场景），每组一条竖向时间线，一回合一个节点。
- 节点默认只有一行：**动作标签 + why**。动作翻成人话：继续追这一点 / 换个角度 / 换到另一段经历 / 收尾；候选人信号也翻：你说不会 / 你求助 / 答得空。
- 节点第二行灰字：ledger（面试官记下的证据账），这是"它当时怎么看你的回答"。
- 被追到的地方点亮：连续两次以上在同一角度追问、或 ledger 里带"存疑 / 说不清 / 没给数字"字样的回合，用强调色左边线标出来，并在组头汇总"这段经历被追了 N 次、2 处存疑"。
- 展开一个节点才看到原对话（候选人那句 + 面试官那句）。
- **不放**：token、耗时、缓存、兜底原因、系统提示词、重放按钮、违规清单。这些留在现有 `/trace` 页（改名"开发者记录"，从报告页尾的链接进入）。

**验收**：`reviewTrail` 单测（动作翻译、点亮规则、分组）；tsc；本地一场真实面试的报告页截图；体验版同一场（把事件文档喂进同一组件）截图；明暗两套。

**明确不做**：让模型再写一段"面试官总结"（已有报告总评，不重复）；逐回合评分；把开发者 trace 页美化。

## 2. 宣传页 `/showcase`

**叙事换成三段，围绕"它像真人面试官一样追问"**：

1. **Hero**：标题不变（"每一场面试，都算数"），副标题改成一句产品事实："一个会顺着你的回答往下追的面试官，面完给你每一条都能回到原话的评分卡。"右侧演示换成**真实回放**：从一场真实模拟面试的事件日志导出 6–8 回合匿名片段（候选人说 → 面试官追问 → 换角度 → 收尾），打字机式循环播放，界面就是现在的房间 UI（不再是"3 / 8 题 · 84 分"）。
2. **它怎么问**：三张并排，每张一个真实回合：左边候选人原话，右边面试官下一问，下面一行小字是面试官当时的 why（来自 §1 的同一数据）。这比"技能包出题，问到点子上"有说服力，也是 §1 页面的预告。
3. **面完你拿到什么**：报告页真实截图（总评 → 失守在哪 → 简历上的说法经不经得起问 → 每条依据带原话），旁边三行文字各配一个可复现的数字：评分卡依据逐字率 0.99、面试官模型不支持结构化输出也能跑通（一次通过 78.6% → 可用 97.0%）、每场成本量级。数字只放硬的，不放"0 条数据经过服务器"这类。
4. **闭环 + 边界**合成一屏：五个环节压成一条横向流程条（保留"画像决定下一场练什么"这句），下面三条边界原文保留（本地、只读、Key 不落服务端）。删掉技能包跑马灯。
5. CTA 不变。

**实现**：`showcase-content.tsx` 重排区块、`copy.tsx` 中英文案重写、`loop-demo.tsx` 改为读一份静态回放 JSON（从真实事件导出、脱敏、手工挑选）。截图用 `docs/images/` 新图（报告页、房间页各一张，明暗各一）。

**验收**：线上 Vercel 预览明暗两套截图；移动端 375 宽不横滚；中英两套文案都过一遍。

**明确不做**：滚动驱动动效、视频、第三方组件库；不改 `/homepage` 及产品内页。
