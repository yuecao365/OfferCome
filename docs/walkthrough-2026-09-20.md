## 3. 这场做得对的（不用动）

- 追问质量：每句都接住上一句（"口径你说得清楚，也承认成功率没对照"），落到机制或数字，同一角度不超过两句；换材料时用一句过渡。
- 跨场记忆起作用了：假设区写"上次没讲清"，六条假设里两条被验证、两条仍没讲清，与上几场对得上。
- 底线只触发 2 次，回合 p95 4.9 s，缓存 79%。
- 备课自选包：ai-agent + project-deep-dive + llm-eval，与 JD 方向一致。

## 5. 对四个模块的优先级建议（待用户定）

1. **判分与报告**（#1–4、#15–19）：用户最先撞到、也是最贵的一段。先修"已问未答不计分"的口径与评分 agent 的结构化输出失败率，再收拾报告文案。
2. **能力画像**（#5、#6）：标签解释与刷新成本。
3. **面试官与记忆**（#7–9、#13–14）：一句多问、开场不接话、内部词、结束时的假发言。
4. **整体评测**：这场没暴露新的评测问题；评分失败率 6/14 值得进 harness 报告盯住。
