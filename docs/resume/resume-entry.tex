\resumeProjectSubline{自研 Agent 运行时、多 Agent 分工、三层 Memory、动作层工具调用控制、事件溯源与面试官黑盒基准}
\vspace{-3pt}
\resumeItemListStart
\resumeItem{\textbf{自研统一 Agent 运行时}：输出契约三级降级（schema 收敛 $\to$ 携校验错误重试 $\to$ 兜底解析）、工具三级权限（放行 / 记账 / 挂起待审）、步数--token--时长--成本四类预算、提示词前缀缓存（命中约 80\%）；结构化输出一次通过率 \textbf{78.6\%}、降级后可用率 \textbf{97.0\%}。}
\resumeItem{\textbf{多 Agent 分工}：备课 Agent 产出能力蓝图与待验证假设，面试官 Agent 按假设追问，评分与汇总 Agent 独立于面试官并使用不同模型避免自证；Agent 间只通过事件日志与结构化产物交接，无共享可变状态。}
\resumeItem{\textbf{三层 Memory}：场内为面试官每回合整份重写的四段 Markdown 笔记，跨场为候选人档案，长期为能力画像；三层同一形态、Agent 自写自读，代码只守格式门。以"待验证剩余条数"与"新信息量"替代时钟与回合配额，主动收尾比例由 \textbf{0.25} 升至 \textbf{0.53}。}
\resumeItem{\textbf{动作层工具调用控制}：面试官每回合先输出结构化决策（追问 / 换题 / 澄清 / 收尾 + 目标）再生成话术，代码按会话状态校验动作并携原因退回，二次违约降级为代码决策；控制点从"事后过滤文本"前移到"执行前校验动作"，提示注入无法改变面试进程。}
\resumeItem{\textbf{事件溯源}：append-only 事件日志为唯一事实源，进度、状态卡、评分切段均为其纯函数投影；任一回合可确定性重放，提示词改动可离线回归。}
\resumeItem{\textbf{InterviewBench 黑盒基准}：面试官实现按统一接口提交、仅凭逐字稿与评分卡打分；对照同模型裸提示词基线，评分卡\textbf{引用不实每场 0.10 vs 0.53}、\textbf{一段多问率 0.24 vs 0.65}。}
\resumeItemListEnd
