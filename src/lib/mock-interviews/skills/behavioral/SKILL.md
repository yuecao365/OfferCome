## 岗位职责与考察重点

行为面在国内互联网公司通常出现在三个位置：技术一面最后十分钟的"聊聊你自己"、主管面（三面）对动机与稳定性的评估、HR 面对价值观与薪资期望的确认。外企（以及国内外企风格的团队）会有独立的 behavioral round，用 STAR 结构逐条追问 leadership、conflict、failure、ambiguity、collaboration 五类故事，每个故事追到"你个人具体做了什么、结果怎么量化、之后改变了什么"为止。

校招候选人的故事多来自实习、课程小组、社团和竞赛，面试官不苛求场面大，看的是能否分清"我"和"我们"、有没有反思、动机是否真实；社招候选人则被重点考察离职原因的一致性、和上级或跨部门的冲突处理方式、带人或推动跨团队事项的实际经历。

面试官最在意三件事：第一，故事是不是真的——细节、时间线、数字能否经得住追问，冲突故事里对方的立场能否被公平地复述；第二，候选人是否有自我认知——失败故事里能否说出自己的责任，反馈故事里能否说出当时的情绪与之后的改变；第三，动机与稳定性——为什么是这个公司、这个岗位，三到五年的方向和岗位是否匹配，遇到不顺时会不会立刻跑。

## 主题

### STAR 结构与追问纵深
- 阶梯：让候选人讲一个故事，看是否自带 Situation/Task/Action/Result → 追 Action 里"你个人"做了什么 → 追 Result 的数字与验证方式 → 追事后改变了什么习惯或机制（STAR-L 的 Learning）
- 好题：讲一件你在最近一段实习或项目里主动推动、不是被分配的事，从背景到结果两分钟以内，之后我会逐句追问。
- 危险信号：Situation 讲了一分半，Action 只有一句；Result 是"效果不错""大家都很满意"；追问细节时故事开始变形。
- 期望信号：结构清晰且 Action 占比最大；有第一人称的具体动作；结果可量化或有第三方反馈；能说出事后的改变。

### 与同事或上级的冲突
- 阶梯：有没有和同事意见不一致的经历 → 对方的理由是什么、你能否公平复述 → 最后怎么达成一致，谁让步、依据是什么 → 如果对方是你的直属上级且坚持己见，你会怎么做
- 好题：讲一次你和评审你代码或方案的人意见相左的经历：对方的观点是什么，你最终是说服了他、被说服了，还是找到第三条路？事后关系怎么样？
- 危险信号：故事里对方是完全不讲理的反派；用"我脾气好就随他了"回避；说不出对方观点的合理之处。
- 期望信号：能中立复述对方立场；有数据或实验来推动而非靠嗓门；结果无论输赢都能保持协作；提到了事后主动修复关系。

### 失败与犯错
- 阶梯：讲一次搞砸的经历 → 你的责任占多少 → 当时怎么补救、影响范围控制在哪 → 之后做了什么让它不再发生，验证过有效吗
- 好题：讲一件你亲手造成的、影响到别人的错误（线上问题、延期、错误的方案）。当时是怎么发现的、你第一时间做了什么、后来改了什么流程？
- 危险信号：拿"太追求完美"当失败；把责任推给环境或他人；改进只有"下次更细心"。
- 期望信号：坦承自己的判断错在哪；有具体补救动作和时间线；改进是机制层面的（checklist、测试、灰度、沟通节奏）。

### 动机与岗位匹配
- 阶梯：为什么投这个岗位和公司 → 对岗位日常工作的理解是否准确 → 和其他 offer 或方向比较时看重什么 → 如果入职后发现工作内容和预期有差距会怎么办
- 好题：你对这个岗位日常一天的想象是什么？你觉得自己哪段经历最接近这种工作，哪方面差距最大？
- 危险信号：对公司的了解只有官网一句话；"大厂平台好"之外说不出具体原因；岗位理解和 JD 明显偏离。
- 期望信号：了解团队的业务与技术特点；能把自身经历和岗位要求对应；对差距有清醒认识并有补足计划。

### 职业规划与稳定性
- 阶梯：三到五年想成为什么样的人 → 这个规划和眼前岗位的关系 → 规划实现的中间里程碑是什么 → 如果公司或行业变化导致规划走不通，你的底线是什么
- 好题：三年后你希望自己在技术深度、业务理解、影响范围三个维度分别到什么程度？现在的岗位能提供其中哪些、不能提供哪些？
- 危险信号：规划是"先进大厂再说"或"做管理"；规划与岗位方向完全无关；说不出任何中间步骤。
- 期望信号：规划具体到能力维度；与岗位有交集；知道自己需要主动争取什么；对不确定性有心理准备。

### 离职或换方向的原因
- 阶梯：为什么离开上一家/上一个方向 → 当时尝试过解决那个问题吗 → 这个原因在新公司会不会重复出现 → 前后几段经历的离职原因是否有共性
- 好题：你上一段实习提前结束，是哪一方先提的？当时是否尝试过调整？如果我们这里出现类似情况你会怎么处理？
- 危险信号：说前东家或前上级坏话；离职原因前后不一致；每段经历都因"没成长"离开却说不出想要什么成长。
- 期望信号：原因客观且有克制；有先尝试解决的动作；能说清新岗位如何避免同样问题。

### 抗压与优先级取舍
- 阶梯：讲一次多任务并行、时间不够的经历 → 你怎么排优先级、依据是什么 → 砍掉了什么、怎么跟相关方沟通的 → 事后有没有因为砍掉的部分出问题
- 好题：如果同一周内有一个线上 bug、一个上级布置的紧急需求、一个你答应同事的评审，你会按什么顺序处理？讲一个类似的真实经历。
- 危险信号：回答"都熬夜做完"没有取舍；不沟通就默默砍需求；把压力全部转嫁给别人。
- 期望信号：有明确的优先级判断标准（影响面、不可逆性、承诺方）；主动同步进度与风险；事后有复盘。

### 接受反馈与自我认知
- 阶梯：最近一次被批评是什么事 → 当时的第一反应和后来的想法 → 你认同的部分和不认同的部分分别是什么 → 之后行为上具体改了什么
- 好题：讲一次别人给你的反馈让你当时不舒服、但后来觉得对的经历。反馈内容是什么？你多久接受的？改了什么？
- 危险信号：说自己没被批评过；对反馈的态度是"我当时就欣然接受了"没有情绪过程；缺点只说"太较真"。
- 期望信号：能复述反馈原文；承认有情绪与反思过程；有可观察的行为变化；能对不认同的部分给出理由。

### 主动性与推动力
- 阶梯：讲一次没人要求你做、你主动做的事 → 为什么觉得应该做、怎么说服别人投入 → 遇到阻力时怎么推进 → 如果最后没做成，你怎么判断该不该继续
- 好题：讲一件你推动别的团队或别的人配合的事：他们一开始为什么不愿意？你用什么方式让事情动起来？最终结果和成本各是什么？
- 危险信号：主动性的例子是"主动加班"；推动方式只有"找领导压"；说不出对方的顾虑。
- 期望信号：能识别对方的利益点；用数据、原型或分阶段承诺降低对方风险；知道什么时候该停。

### 模糊需求与不确定性
- 阶梯：接到过描述不清的任务吗 → 你怎么把它变清楚、问了谁、问了什么 → 在信息不全时怎么决定先做什么 → 做到一半发现方向错了怎么办
- 好题：讲一次你拿到的需求只有一句话的经历。你做了什么让它变成可执行的？你是先动手还是先确认？为什么？
- 危险信号：所有需求都"照做"从不追问；或反过来不问清楚就闷头做完再返工；说不出澄清需求的具体问题。
- 期望信号：有结构化的澄清方式（目标、边界、验收标准）；能用最小原型换取信息；知道沉没成本该断就断。

### 团队协作与角色定位
- 阶梯：团队里你通常扮演什么角色 → 有没有为了团队目标放弃自己方案的经历 → 队友不给力时你怎么处理 → 你觉得自己最不擅长和什么样的人合作
- 好题：小组项目里如果一个成员长期不交付，你会怎么做？讲一个真实经历，包括你和他沟通的具体内容以及最终结果。
- 危险信号：角色定位是"什么都能干"；队友问题一律"我自己做了"；对合作困难的人只有负面评价。
- 期望信号：对自己的角色有清醒认识；有直接沟通的具体动作；能区分能力问题与意愿问题；知道何时升级给上级。

### 价值观与诚信边界
- 阶梯：有没有被要求做你觉得不对的事 → 你当时怎么判断对错 → 拒绝或妥协的方式是什么 → 如果拒绝会影响绩效，你的底线在哪
- 好题：如果上级要求你把一个明知有风险的功能在没有测试的情况下上线以赶节点，你会怎么做？有类似的真实经历吗？
- 危险信号：回答完全顺从；或回答过于理想化没有任何妥协余地；说不出判断标准。
- 期望信号：能区分可协商与不可协商；有降低风险的折中方案（灰度、开关、留证据）；愿意承担拒绝的后果。

### 薪资期望与 offer 决策
- 阶梯：期望薪资多少、依据是什么 → 现在手上有哪些选择、比较维度 → 如果薪资低于期望但其他条件好，怎么权衡 → 你最看重的一项不能让步的是什么
- 好题：你说期望 X，这个数字是怎么来的？如果我们给到 X 的 85% 但岗位方向完全匹配，你会怎么决定？
- 危险信号：报价明显脱离市场且说不出依据；前后报价不一致；把所有 offer 都说成"在考虑"没有任何倾向。
- 期望信号：报价有依据（市场区间、自身水平）；比较维度清晰；对取舍有真实的优先级。

## 好题 / 坏题对比

- 坏：你有什么优点和缺点？
- 好：讲一次别人的反馈让你当时不舒服但后来证明是对的经历，反馈原话是什么，你改了什么？
- 坏：你的抗压能力怎么样？
- 好：讲一次时间不够必须砍需求的经历：你砍了什么、依据是什么、怎么和相关方说的、事后有没有因此出问题？
- 坏：你能接受加班吗？
- 好：如果同一周内线上问题、上级的紧急需求和你答应同事的评审撞在一起，你会怎么排序并沟通？讲一个真实经历。

## 项目结合钩子

- 简历出现"团队负责人""组长""PM" → 追怎么分工、有没有成员不交付、冲突怎么解决、自己写了多少代码。
- 简历出现多段短期实习 → 追每段离开的原因是否一致、有没有先尝试解决。
- 简历出现"推动""协调""跨部门" → 追对方一开始的顾虑、用什么方式让事情动起来、成本是什么。
- 简历出现"从零搭建" → 追为什么由你来做、当时的不确定性、做错过哪个方向。
- 简历出现社团、学生会、志愿者经历 → 追一次真实的冲突或失败，验证是否只是挂名。
- 简历出现 gap 期或转方向 → 追决定过程、当时的替代选项、现在回看是否正确。
- 简历出现明显超出年级的成果 → 追个人贡献边界与导师/团队的角色。

## 出题原则

- 每个软素质维度都要落到一个真实故事上追问，不接受"我认为我会……"的假设性回答；假设题只用作引子，紧接着必须问"有类似的真实经历吗"。
- 冲突和失败故事必须追到"对方的合理之处"和"自己的责任"，只有反派与借口的故事不给分。
- 校招不苛求场面，关注是否分清"我"与"我们"、有没有反思；社招必须交叉验证离职原因、冲突处理方式和推动跨团队事项的真实经历。
- 不问涉及婚育、家庭、地域、宗教等与岗位无关的隐私问题；薪资问题只问依据与取舍逻辑，不评价数字高低。
